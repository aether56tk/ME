Cookie & Tracking Policy

Last updated: 12 October 2026

What this site currently uses

The current website code does not intentionally add analytics, advertising pixels, social-media widgets, video embeds or a cookie-based preference tracker. It loads the Supabase JavaScript library from jsDelivr and sends enquiry form submissions to Supabase. The hosting provider may independently process technical logs or use technologies necessary to deliver its service; review the providers’ current notices for their practices.

Do we show a cookie-consent banner?

A banner should not be used as a substitute for checking what the live site actually stores or loads. Based on the current source code, no non-essential analytics or advertising cookies are intentionally configured, so this version does not display an “accept all” banner. This is not a claim that the hosting platform, browser or third-party providers never use cookies or logs. Re-check browser storage and network requests after any code or provider change.

Third-party services

  • GitHub Pages: hosts the website.
  • jsDelivr: serves the Supabase JavaScript library.
  • Supabase: receives and stores submitted enquiry fields.

Opening a mail link transfers you to your email application or provider. No embedded external media is intentionally used in the current page.

Changes

If analytics, marketing, embedded media or other non-essential storage is added, update this policy and implement a consent mechanism before loading technologies that require prior consent under applicable law. Provide a way to change preferences later if such a mechanism is introduced.

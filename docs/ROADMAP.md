# Personal Roadmap

This roadmap is directional, not a strict deadline contract. Reorder it when exams, health, family, or real-life commitments change.

## Phase 1 — Stabilise and prepare
**Priority: November examination period**

- [ ] Map syllabus units and previous questions for each current subject.
- [ ] Prioritise the next examination topics instead of trying to finish everything at once.
- [ ] Keep the SSD backlog visible in the weekly plan.
- [ ] Use short study starts, active recall, and spaced revision.
- [ ] Maintain a realistic sleep window and hostel/mess meal routine.
- [ ] Make the first task for the next day obvious before sleeping.

**Done means:** a usable revision map, regular small study sessions, and clear evidence of topics revised—not a perfect timetable.

## Phase 2 — Rebuild BASLP fundamentals
- [ ] Review anatomy and physiology relevant to hearing, speech, language, and swallowing.
- [ ] Practise explaining core concepts in plain language.
- [ ] Learn case history, assessment selection, test procedures, and interpretation.
- [ ] Revisit audiometry, speech audiometry, masking, immittance, OAE, and ABR concepts.
- [ ] Practise clinical documentation using fictional or properly de-identified examples.
- [ ] Keep supervised clinical practice within institutional rules.

**Done means:** explain a concept, justify an assessment choice, interpret a practice case, and identify limits or uncertainties.

## Phase 3 — Stronger clinician and researcher
- [ ] Build case-based learning notes.
- [ ] Learn research methods, statistics, ethics, and critical appraisal.
- [ ] Track project questions, methods, limitations, and next experiments.
- [ ] Seek faculty/mentor feedback before presenting clinical or research claims.
- [ ] Document reproducible methods and honest limitations.

## Phase 4 — Medical-device security and safety
- [ ] Strengthen networking, Linux, scripting, threat modelling, and defensive monitoring.
- [ ] Learn secure design principles and privacy risk assessment.
- [ ] Explore BLE, mobile companion applications, cloud interfaces, identity, logging, and access control in authorised lab environments.
- [ ] Learn medical-device risk management, quality systems, and relevant standards from authoritative sources.
- [ ] Produce a portfolio showing evidence, scope, limitations, and mitigations—not just tool names.

## Phase 5 — Ship useful projects
- [ ] Give each active repository a clear README, setup instructions, roadmap, and limitations.
- [ ] Add tests before major feature expansion.
- [ ] Record issues and decisions.
- [ ] Make small, reviewable commits.
- [ ] Distinguish prototype, tested, and validated functionality.
- [ ] Ask for feedback and improve based on evidence.

## Phase 6 — Personal growth / Project Iron Will
- [ ] Build sustainable strength and cardiovascular fitness.
- [ ] Develop grooming, communication, and dependable routines.
- [ ] Track effort and recovery without punishment.
- [ ] Work toward financial independence and the ability to support family.
- [ ] Become a better son, friend, colleague, and future partner through actions and boundaries.

## Weekly priority rule

Choose no more than **three active priorities**:
1. **Must do:** one deadline-sensitive academic task.
2. **Build:** one clinical, research, or technical task.
3. **Maintain:** one small health or life-system task.

Everything else can wait. Reprioritising is not failure.

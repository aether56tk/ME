## How to use this repository

1. At the start of a week, pick **one academic priority, one project priority, and one personal-care priority**.
2. Break each into a next action that can be started in 5–15 minutes.
3. Update the goal tracker when something changes.
4. Use the weekly review to learn, not to judge.
5. Record achievements with evidence: a completed unit, tested feature, written report, supervised skill practised, or meaningful contribution.

## Operating principles

- **Start tiny:** open the notes, write three recall questions, or work for five minutes.
- **Flexible beats rigid:** time blocks are guides, not punishments.
- **Return without guilt:** never try to make up every missed task.
- **Protect fundamentals:** sleep, food, water, movement, and human connection support the work.
- **Evidence over claims:** distinguish ideas, prototypes, tested features, and validated outcomes.
- **Build safely:** never put patient-identifying information, private health details, credentials, tokens, or confidential clinical documents in this public repository.
